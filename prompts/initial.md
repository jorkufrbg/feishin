# Initial prompt

## Context

You are tasked with analyzing a provided codebase snippet or description. Your goal is to deliver a clear, concise overview of the project, covering its main purpose, structure, and functionality based on the code and information presented. Additionally, identify and list all required dependencies indicated or implied within the codebase, including libraries, frameworks, or external tools needed to run or build the project.

Approach the task methodically:

1. Review the codebase content carefully, noting key files, modules, classes, functions, and their purposes.
2. Summarize the project’s objectives and main features in your overview.
3. Examine package management files (e.g., package.json, requirements.txt, pom.xml) or code imports to identify dependencies explicitly.
4. Mention any inferred dependencies based on code usage patterns or conventions.
5. Provide your findings in a structured, easy-to-understand summary.

Be thorough yet concise, ensuring your response is accessible to readers with a basic understanding of programming.

## Output Format

Provide the output as a structured summary with two clear sections:

- **Project Overview:** A brief description outlining the purpose, scope, and primary components of the project.
- **Required Dependencies:** A list of all identified dependencies with any relevant versions or details if available.

Use bullet points or numbered lists for clarity where appropriate.
